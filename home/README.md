## Featured Project

### Google Sheet Loader

Google Sheet 데이터를 Unreal Engine 프로젝트에서 사용할 수 있도록 불러오고, 데이터 파싱과 에셋 생성을 자동화하기 위해 진행한 프로젝트입니다.

초기 Parser와 Fetcher 구조부터 플러그인 개선, Data Table 및 Data Asset 생성, 비동기 에셋 로드 적용 과정을 기록하고 있습니다.
