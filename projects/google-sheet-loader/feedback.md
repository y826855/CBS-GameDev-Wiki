# 피드백

Google Sheet Loader 플러그인에 대해 받은 피드백과 개선 내용을 정리하는 페이지입니다.

아래 내용은 현재까지 받은 의견을 정리한 것으로, 구체적인 구현 방법과 적용 여부는 아직 확정하지 않았습니다.

## Header 행 지정

현재는 Sheet의 첫 번째 행을 항상 Header로 사용합니다.

첫 번째 행으로 고정하지 않고, 데이터 구조에 따라 Header로 사용할 행을 유동적으로 지정할 수 있으면 좋겠다는 의견을 받았습니다.

## Encoding 안정성

Sheet 데이터를 가져오는 과정에서 간헐적으로 Encoding이 깨지는 현상이 있었습니다.

문제가 발생하는 조건을 확인하고 안정적으로 처리할 수 있는지 검토가 필요합니다.

## JSON 형태의 사용

Sheet 데이터를 JSON처럼 사용할 수 있으면 좋겠다는 의견을 받았습니다.

원하는 데이터 변환 방식과 접근 형태에 대해서는 추가 확인이 필요합니다.

## Parser 제작 과정 개선

새로운 Parser를 제작하는 과정을 더 쉽게 구성할 수 있으면 좋겠다는 의견을 받았습니다.

현재 제작 과정에서 반복되거나 복잡한 부분을 확인한 뒤 개선 방향을 정리할 예정입니다.
