# Google Sheet Loader

Google Sheet 데이터를 Unreal Engine 프로젝트에서 사용할 수 있도록 불러오고, 데이터 파싱과 에셋 생성을 자동화하는 플러그인입니다.

HTTP를 통해 Sheet 데이터를 가져온 뒤 프로젝트별 Parser로 처리할 수 있습니다. 여러 설정을 한 번에 확인하고 갱신하는 Dashboard와 작업 진행 상태, 취소 및 자동 저장 기능도 제공합니다.
